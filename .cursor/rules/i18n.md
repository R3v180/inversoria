# i18n (ES/EN)

- All user-visible strings in Streamlit UI must use `_('KEY')` from `i18n.py`.
- Add both `es` and `en` for every new key in `TRANSLATIONS`, `i18n_ui_extra.py`, or via `scripts/sync_cfg_i18n.py` for `CFG_KEY_*`.
- Config parameters: `CFG_KEY_{SETTING}`, optional `CFG_HELP_{SETTING}`, choices `CFG_CHOICE_{KEY}_{value}`.
- Validation errors: raise `ConfigValidationError` with `ERR_CFG_*` codes; display via `format_config_error` / `format_validation_error`.
- After changing `CONFIG_SCHEMA`, run `python scripts/sync_cfg_i18n.py`.
- Before PR: `python scripts/audit_i18n.py --fail-on-warn` and `python -m unittest tests.test_i18n_parity -v`.
