# 🏛️ INVERSOR IA - Agent Edition v5.0

**INVERSOR IA** es mucho más que un bot; es un **Agente de Trading Autónomo** de grado institucional. Diseñado para operar en el mercado de criptomonedas (Crypto.com) fusionando el poder de las redes neuronales de Google (Gemini) con un motor de ejecución técnica de precisión quirúrgica.

---

## 🛰️ La Evolución: ¿Qué hay de nuevo en v5.0?

### 🧠 1. Asistente IA Conversacional (Copiloto)
Hemos integrado un **Cerebro Conversacional** con memoria persistente.
- **Diálogo Estratégico**: Debate con tu bot sobre novedades del mercado o pídele opinión sobre tu cartera en lenguaje natural.
- **Memoria Contextual**: La IA conoce tu balance real, tus posiciones abiertas y los últimos eventos del mercado para darte asesoría personalizada.
- **Acción Segura**: La IA propone, tú dispones. Soporte para órdenes propuestas por chat con confirmación de seguridad.

### 🛰️ 2. Radar Dinámico "Vigilancia Total"
El bot nunca duerme, y ahora ve más que nunca.
- **Curation AI**: Un filtro inteligente procesa el Top 30 de volumen y selecciona dinámicamente las 15-20 monedas más prometedoras.
- **Escaneo Multi-Activo**: Monitorización simultánea de toda la Watchlist con análisis técnico individualizado.
- **Detección de Narrativas**: Capacidad de identificar tendencias como Memecoins políticas o proyectos de infraestructura en tiempo real.

### 💻 3. Command Center de Última Generación
Una interfaz diseñada para la toma de decisiones rápida.
- **Equity Real-Time**: Gráficas de patrimonio sincronizadas con precisión de segundo, integrando el valor de cada activo en cartera.
- **Logs Inteligentes**: Registro de operaciones enriquecido con marcas de tiempo y filtrado de ruido para centrarse en lo importante.
- **Terminal Dual**: Control total de parámetros, rotación de capital y gestión de riesgos desde un panel unificado.

---

## 🚀 Características Core

*   **🛡️ Gestión de Riesgo**: Trailing Stop Loss dinámico, SL basado en ATR y filtros de volatilidad (ADX).
*   **🔄 Rotación de Capital**: Capacidad de cerrar posiciones débiles automáticamente para entrar en señales de mayor confianza.
*   **🤖 Fallback AI**: Sistema híbrido que conmuta entre Gemini 1.5 Pro, Flash y Groq para garantizar operatividad 24/7.
*   **📊 Historial & Analítica**: Diario de trading persistente con capturas del razonamiento de la IA tras cada operación.

---

## 🛠️ Stack Tecnológico
- **Core**: Python 3.11+
- **Brain**: Google Gemini 1.5 Pro / Flash & Groq (Llama 3)
- **UI**: Streamlit (Premium Custom CSS)
- **Engine**: CCXT / Pandas-TA
- **Database**: SQLite (Sync Local-Cloud)

---

## ⚙️ Despliegue Rápido
1.  **Clonar**: `git clone https://github.com/R3v180/inversoria`
2.  **Configurar**: Edita el archivo `.env` con tus llaves de API.
3.  **Instalar**: `pip install -r requirements.txt`
4.  **Lanzar UI**: `streamlit run app.py`
5.  **Activar Agente**: `python bot_daemon.py`
